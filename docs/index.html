Why Mind the Map?

⌨️ Keyboard First

Navigate, create, and edit nodes without touching your mouse. Every action has a keyboard shortcut.

🚀 Lightning Fast

Built with Tauri and React for native performance. Opens instantly and handles large maps smoothly.

📋 Smart Clipboard

Paste indented text or HTML lists and they become structured nodes. Export to other apps like Miro.

🎨 Two Views

Switch between mind map visualization and outline view. Use whatever fits your current task.

🏷️ Icon Markers

Mark nodes with icons for status, priority, or categories. Quick cycle through icon variants.

💾 Local Files

Your data stays on your machine in simple JSON files. No cloud, no account, no tracking.

Collapse & Expand

Manage complexity by collapsing nodes you don't need to see right now.

KeyAction
SpaceToggle collapse for selected node
Shift+Alt+SpaceCycle through collapse states for all descendants

Three-State Collapse Cycle

When you press Shift+Alt+Space, the node's children cycle through three states:

1. Collapsed
All children hidden
→
2. Expanded (except completed)
Shows all except nodes marked ✓
→
3. Fully Expanded
Everything visible
→
Back to 1...
💡 Tip: The "Expanded except completed" state is great for focusing on what's left to do. Mark finished items with a ✓ icon, then use the cycle to hide them.

Clipboard & Export

Mind the Map handles copy/paste intelligently, preserving structure when possible.

KeyAction
⌘+CCopy selected nodes
⌘+XCut selected nodes
⌘+VPaste as children of selected node
⌘+Shift+MCopy for Miro

Pasting from External Apps

When you paste text from other apps, Mind the Map tries to preserve structure:

  • Indented text — Indentation levels become parent/child relationships
  • HTML lists — Copied lists from web pages maintain their hierarchy
  • Plain text — Each line becomes a separate sibling node

Copy for Miro

Use ⌘+Shift+M to copy nodes in a format optimized for Miro's mind map import.

How to use with Miro:
  1. Select the nodes you want to export
  2. Press ⌘+Shift+M to copy
  3. In Miro, use the Mind Map tool and paste
  4. Choose "Table" format in Miro's paste dialog

Icons & Markers

Add visual markers to nodes for status tracking, priorities, or categorization.

KeyAction
IOpen icon picker
Click existing iconCycle to next variant in category

Icon Categories

  • Progress — Empty, half, complete checkmarks
  • Priority — Numbered priorities (1-4)
  • Flags — Different colored flags
  • Symbols — Star, heart, warning, question, etc.
💡 Tip: Click on an existing icon to cycle through variants. For example, clicking a "Priority 1" icon changes it to "Priority 2".
